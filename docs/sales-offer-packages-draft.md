## 2. Proposal stages (standard flow)

Discovery call → written scope + fixed proposal (inclusions, exclusions, timeline, milestones) → deposit/start (milestone TBC) → build with staged previews → review/launch → handover + optional care. No lock-in beyond the agreed scope; source ownership terms TBC by owner.

## 3. Qualification checklist (use before quoting)

- Business stage & location (AU/KE/remote); existing site/domain/hosting?
- Required outcome in one sentence (enquiries? bookings? internal tool?)
- Budget band discussed openly (no published anchors — ask range)
- Timeline driver; decision-maker; content/assets ready?
- Preferred channel (WhatsApp/email/phone) — matches current manual flow
- Red flags: guaranteed-ranking requests, scope without assets, "free until it works"

## 4. Quote/proposal outline (non-spammy, manual-channel friendly)

1. One-line recap of their ask + why it fits a package
2. Scope table (in/out), assumptions (content, revisions, access)
