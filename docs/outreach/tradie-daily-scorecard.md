## Definitions

- **Candidate**: a business found, not necessarily suitable.
- **Qualified**: official evidence verified and score at least 12/20 with no exclusion flags.
- **Draft reviewed**: one genuine personalised message checked; **not sent**.
- **Sent**: outbound action completed from an authorised channel; use the actual send timestamp.
- **Reply / call / quote / won / lost**: log only when the event actually happens; don't infer a win from a positive response.
- **Follow-up due**: one optional courteous reminder, never after an opt-out.

## Private pipeline status mapping

`Researching → Qualified → Draft Reviewed → Contacted → Replied → Call Booked → Quote Sent → Won / Lost / No Contact`

Do **not** confuse outbound research statuses with the inbound enquiry-inbox workflow (`New → Contacted → Qualified → Proposal Sent → Won/Lost`). Conversion reporting should keep the two sources separated until a reviewed private CRM integration maps them correctly.

Track people/business-specific data only in the owner-controlled system; never commit a filled scorecard, customer names, business contact details or dates linked to specific prospects to this public repository.
