SmartDuka

Retail POS & Inventory Platform

SmartDuka is a free, open-source point-of-sale and inventory management system built for retailers. Sales, stock, reports and M-Pesa payments run from one web app on phones, tablets and counters — with no subscriptions and no user data collected.

The Problem

Small retailers often run on paper records, chat threads and memory — or pay recurring subscriptions for point-of-sale software they only partly use. SmartDuka was built around a simple premise: a capable POS and inventory system should be accessible to every business, not just the ones that can afford licences.

What We Built

SmartDuka is a web-based point-of-sale and inventory platform aimed at African retailers. It is free and open source — no subscriptions, no hidden fees and no user data collection — and it can be installed on a device for faster access and offline support.

Point of Sale

Sell at the counter from a phone, tablet or computer with a checkout flow designed for everyday retail.

Inventory Tracking

Real-time stock tracking so retailers always know what is on the shelf and what needs restocking.

M-Pesa Payments

Integrated M-Pesa payments alongside regular sales, built for how Kenyan retail actually transacts.

Reports & Analytics

Sales reports and AI-assisted analytics that turn day-to-day transactions into useful visibility.

Key Capabilities

  • Sales and checkout at the counter
  • Real-time inventory and stock tracking
  • M-Pesa payment integration
  • Barcode scanning
  • Reports and analytics
  • Installable app with offline support

Platform & Technical Overview

Modern Web Application

A Next.js web application that runs in the browser on phones, tablets and desktop counters — no till hardware required.

Installable PWA

Ships with a web app manifest so it can be installed on a device for faster access and offline support.

Free & Open Source

Free to use with no subscriptions or hidden fees, and designed so no user data is collected.
